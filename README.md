# ShoppingCart

A modern shopping cart application built with **React** and **Vite**, offering a fast and responsive user experience for managing products and checkout.

## Features

- 🛒 Add/remove items from cart
- 💰 Real-time price calculations
- ⚡ Fast performance with Vite bundler
- 📱 Responsive design
- 🔍 Product search and filtering
- 🧾 Item quantity updates and cart summary

## Tech Stack

- **React 19** – UI library
- **Vite** – Build tool and dev server
- **JavaScript** – Core language
- **ESLint** – Code quality

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/bofrank/ShoppingCart.git
cd ShoppingCart
npm install
```

### Development

Run the dev server:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

Create an optimized production build:

```bash
npm run build
```

### Linting

Check code quality:

```bash
npm run lint
```
